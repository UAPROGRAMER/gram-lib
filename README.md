# Gram Lib

Library for training and using n-gram LMs writen in C++. Any context size and amount of different tokens.

## Usage

To use with CMake:

```cmake
add_subdirectory(<path-to-gram-lib>)
target_link_libraries(<target> PUBLIC|PRIVATE|... GramLib)
```

## Gram Tool

Used as a command line tool for training 10-gram with 78 tokens (characters and symbols). Will be more general in the future.

Usage:
```cmd
gramtool [-h | --help]
gramtool [-t | --train] <trainer> <data>
gramtool [-b | --tobrain] <trainer> <brain>
gramtool [-p | --predict] <brain> <file> <amount>
gramtool [-T | --printtrainer] <trainer> <file>
gramtool [-B | --printbrain] <brain> <file>
```
